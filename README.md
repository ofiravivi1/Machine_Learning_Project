# Fashion MNIST Classification - ANN from Scratch

פרויקט זה מציג מימוש של רשת ניירונים מלאכותית (ANN) שנבנתה "מאפס" באמצעות ספריית Numpy בלבד, ללא שימוש בספריות Deep Learning חיצוניות. המודל מאומן לסווג תמונות של פריטי לבוש מתוך המאגר Fashion MNIST ל-10 קטגוריות שונות.

### דגשים טכניים:
* **ארכיטקטורה**: רשת רב-שכבתית הכוללת שכבת קלט, שכבה נסתרת ושכבת פלט.
* **תהליך הלמידה**: מימוש ידני של Forward Propagation לחיזוי ו-Backpropagation לעדכון המשקולות.
* **אופטימיזציה**: שימוש בפונקציות אקטיבציה ReLU ו-Softmax, בתוספת אתחול משקולות לשיפור הביצועים.
* **ניהול ניסויים**: ביצוע Grid Search לכיוונון היפר-פרמטרים ובדיקת אמינות המודל באמצעות 5-fold Cross Validation.
* **תוצאות**: המודל השיג דיוק של כ-76% על נתוני הבדיקה (Test Set).

### התקנה והרצה:
1. **התקנת ספריות**: יש להתקין את הספריות הנדרשות לפרויקט על ידי הרצת הקובץ: `pip install -r requirements.txt`.
2. **הרצת המודל**: יש לפתוח את המחברת `Fashion_MNIST.ipynb` ולהריץ את התאים לפי הסדר.
3. **תיקיית נתונים**: יש לוודא שקבצי ה-CSV של הנתונים נמצאים בתוך תיקייה בשם `fashion mnist` באותו נתיב של המחברת.
